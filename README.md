# Croma — documentação

Servidor de mídia pessoal com identidade visual própria, feito sobre o Jellyfin (v12.4). Reúne filmes, séries, música, fotos, TV ao vivo e livros. O foco inicial é o desktop e a TV Samsung QN90B (Tizen 6.5).

Este repositório (`croma-doc`) é a **documentação** do projeto, o hub: visão geral, arquitetura e especificações. O código e a marca ficam em repositórios próprios, na organização [`Croma-plataform`](https://github.com/Croma-plataform), clonados dentro desta pasta:

| Repositório | O que é |
|---|---|
| [`croma-identidade`](https://github.com/Croma-plataform/croma-identidade) | Identidade visual (v0.1 "Barras" oficial) |
| [`croma-servidor`](https://github.com/Croma-plataform/croma-servidor) | Servidor (Jellyfin v12.4 oficial, scripts e plugins) |
| [`croma-web`](https://github.com/Croma-plataform/croma-web) | Interface web, compartilhada pelo desktop e pela TV |
| [`croma-desktop`](https://github.com/Croma-plataform/croma-desktop) | App desktop |
| [`croma-tizen`](https://github.com/Croma-plataform/croma-tizen) | App da TV Samsung |
| [`croma-android`](https://github.com/Croma-plataform/croma-android) | App Android (criado, ainda não implementado) |
| [`croma-v1`](https://github.com/Croma-plataform/croma-v1) | Croma v1, arquivado |
| [`.github`](https://github.com/Croma-plataform/.github) | Página de perfil da organização (pasta local `croma-org/`) |

- [`CROMA.md`](CROMA.md): repositórios, versões, arquitetura, mapa do código e como clonar tudo.
- [`specs/`](specs/): especificações (coleções, tags, bibliotecas caseiras).
